# 曜炎 Dashboard｜標準財務流程 v7

## 正常作業順序

1. Google 日曆建立檔期，Dashboard 自動建立專案。
2. 報價確認後，專案價回寫為合約總額。
3. 在「請款／收款」建立訂金、尾款或全額款，填寫請款日後才形成應收帳款。
4. 每次銀行入帳各自按「登記收款」，同一筆請款可以保留多筆收款日期與金額。
5. 專案與公司支出分別記錄成本日期、廠商請款日、預計付款日及實際付款日。
6. 財務總覽追蹤應收帳齡、廠商應付與未來 30 天收付款。

## 金額定義

| 名稱 | 計算方式 |
|---|---|
| 專案價 | 已確認報價的含稅總額 |
| 尚未請款 | 專案價－累計已請款 |
| 應收帳款 | 已請款－該請款累計已收款 |
| 全案待收 | 專案價－累計已收款 |

## 舊資料相容

- 既有 `projects`、`payments`、`quotations`、`expenses` 與 `companyExpenses` 不需搬移。
- 舊版款項中的單一 `receivedAmount / receivedDate` 會先正常顯示。
- 第一次替該款項新增新版收款紀錄時，舊收款會自動轉成一筆 `receipts` 紀錄，不會重複計算。
- 舊支出沒有付款追蹤欄位，預設視為已付款；編輯舊支出時會以原成本日期帶入實際付款日。
